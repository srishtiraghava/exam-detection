## Client-Side Implementation
- Only non-sensitive data (Hold Time, Inter-Key Gap, sequence) is logged. `event.key` is intentionally not captured to preserve privacy.
- Uses the `crypto.subtle.digest("SHA-256")` API natively in the browser.

## Server-Side Implementation
- Completely reconstructs the Merkle root independently using `hashlib.sha256` using the exact same canonical string format (`sequence|keyDownTime|keyUpTime|holdTime|interKeyGap`).
- Logs a `KEYSTROKE_ANOMALY` to the existing `alerts.log` if the variance is near-zero or if >50% of the keystrokes have incredibly small gap times (< 25ms).
- Logs `MERKLE_TAMPERING` if `clientRoot != serverRoot`.

## Merkle Algorithm
- Leaves are generated by hashing the canonical event representation.
- The tree is built iteratively layer by layer. If an odd number of leaves exists, the final leaf's hash is concatenated with itself (as agreed in the documentation).

## Database Changes
- No formal database schema changes (the existing architecture writes purely to `logs/alerts.log`). 
- Alerts generated by the server are automatically visualized on the existing Flask dashboard.

## How to Run
1. Start the Flask Dashboard:
   ```bash
   python src/dashboard/app.py
   ```
2. Navigate to `http://localhost:5000/exam` to view the exam interface.
3. Start typing in the text box. The behavior is recorded silently in memory.
4. Click **Submit Exam**. 
5. Tampered payloads and anomalous typing behavior will automatically appear in `http://localhost:5000/` as an alert.
